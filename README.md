# Algorithms Visualizer

This project visualizes sorting and binary search tree (BST) algorithms using **Pygame**.

## 🧩 Algorithms Implemented

### 🔢 Sorting Algorithms
- Bubble Sort  
- Selection Sort  
- Insertion Sort  
- Merge Sort  
- Heap Sort  
- Quick Sort  
- Counting Sort  
- Radix Sort  
- Cocktail Shaker Sort  
- Shell Sort  
- Bucket Sort  
- Comb Sort  

### 🌳 BST (Binary Search Tree) Algorithms
- Create  
- Search  
- Insert  
- Remove  
- Traverse (Inorder)  
- Traverse (Preorder)  
- Traverse (Postorder)
